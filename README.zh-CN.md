## 关于奶蛋

相传奶蛙降世之时，还有一枚黄色的蛋落在人间。无人见过是谁下的，也无人知道里面是什么。人们将它供在殿中，等了许多年，蛋没有孵化，倒是从供桌上滚下来，把地砖砸出了一个坑。后世称其为“奶蛋”。

有人试过水煮，有人试过火烤，皆不能使其开裂。直到一位工匠拿弹簧将它弹了出去，奶蛋撞过几根铁钉，落入一处窄口，竟变成了数枚。众人连夜拆掉供桌，改造了一台机器。

这便是蛋珠机。从此，再也没人关心奶蛋里能孵出什么，只关心下一次能掉出来几枚。

## 一颗奶蛋，满场乱弹

一台以奶蛋为主角的街机风格弹珠机。奶蛋沿右侧轨道弹向上方，穿过钉板，最后落入底部通道。进入亮灯通道，才算命中。

选择投入数量，锁定倍率和亮灯通道，再蓄力发射。发射力度会实际影响奶蛋的运动，落点并非预先指定。

## 怎么玩

1. **选择投入：** 用 +、− 调整数量，可切换每次增减 1、5 或 10 颗。
2. **启动本局：** 锁定倍率与亮灯通道。
3. **蓄力发射：** 按住发射控件，松开发射；电脑也可按住空格键，再松开。
4. **看落点：** 命中亮灯通道，获得投入数量 × 倍率的奶蛋。

初始库存为 100 颗，每局最多投入 50 颗。启动锁定时扣除投入；力度不足、未进入钉板区的发射可以重试，不重复扣除。

## 打开就能玩

无需下载安装，支持电脑与触屏设备。游戏界面目前为中文。

奶蛋全部为虚拟数量，不涉及支付、现金价值、兑换或交易。

### 本地运行

使用任意静态服务器服务 `dist` 目录，无需安装依赖。

### 实现

静态 HTML/CSS/Canvas，无远程运行依赖。`dist/physics.js` 为固定 240 Hz 的圆体、钉子与轨道碰撞；`dist/game.js` 负责操作、灯光、音效与库存结算。

角色素材为根据已审阅的奶蛋、奶蛙参考生成的初版素材，后续可随美术打磨替换。

### GitHub Pages

设置 Pages 从 `main` 分支的 `/(root)` 部署。根目录入口自动进入 `dist/`。
